# 岩序 · 定线模拟器

在岩壁照片上画岩点，转到 3D 看抓口和走法。[打开岩序](https://pigeon6941.github.io/crux-studio/)

1. 选「新建线路」，拍摄或导入一张岩壁照片。
2. 画一条线作抓边，或圈出整块岩点，点「生成岩点」。
3. 在 3D 里转动查看。要推敲动作，可进入「动作」选择岩点顺序和人体尺寸。

照片、线路和墙面识别都在自己的设备上处理。换设备前可从工作台菜单下载备份，再在另一台设备的线路库导入。
